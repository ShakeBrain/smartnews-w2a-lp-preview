Design Notes 構成メモ

  • Topic Hub template (8 LPs): Shared template. Only color / headline / sample articles / FAQ / publisher list differ per category. Topic Hub 型 (8本): 同一テンプレ、カテゴリ差異は色 / 見出し / サンプル記事 / FAQ / publishers のみ.
  • Article data: Populated daily into the Sheet from the Meta catalog SmartNews maintains for ad delivery, last_day_all_articles (id=24485230187801062, ~19K products, last 24h). GitHub Actions runs at 09:00 JST; manual trigger available via workflow_dispatch. 記事データ: SmartNews が Meta 広告用に維持する catalog "last_day_all_articles" (id=24485230187801062, ~19K products 直近24h) から日次で最新記事を Sheet に populate. GitHub Actions が 09:00 JST 自動実行, workflow_dispatch で手動更新可.
  • Copy source: Reused directly from the performance_label=BEST assets on the existing Google Ads UAC campaigns (proven winning phrases). コピーソース: Google Ads UAC の performance_label=BEST asset をそのまま流用 (勝ってる言葉).
